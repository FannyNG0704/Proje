# Іспанська + теорія на права (permiso B, DGT) — ⏸ пізніше

Чернетка плану. Деталі (актуальні правила, ціни, терміни) перевіримо, коли почнемо —
правила DGT змінюються.

## Проблема

Розмовна іспанська є, але словник малий, а тест DGT написаний офіційною мовою,
з «пастками» у формулюваннях (`salvo`, `excepto`, `únicamente`, `en ningún caso`, `está permitido`…).

## План

1. **Словник водія** — тематичні списки: дорога і розмітка, знаки, частини авто, маневри,
   учасники руху, документи і штрафи. Кожне слово: іспанською → українською → приклад з тесту.
2. **Мова тестів** — розбір типових формулювань і пасток у питаннях.
3. **Теми теорії** по блоках: знаки, пріоритет, швидкість, обгін, паркування, алкоголь і
   наркотики, безпека, перша допомога, механіка, документи і бали (`permiso por puntos`).
4. **Тести** — щодня, з розбором кожної помилки (чому неправильно + нове слово в словник).
5. **Пробні іспити** в умовах, близьких до реальних.

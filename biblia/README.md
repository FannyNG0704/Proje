# Біблія іспанською — ⏸ пізніше

Чернетка плану.

## Проблема

Класичні переклади (наприклад, **Reina-Valera 1960**, найпоширеніший серед протестантів
іспаномовного світу) написані старшою, «книжною» мовою: `vosotros`, старі форми дієслів,
рідкісні слова. Розмовної іспанської для них мало.

## Підхід

1. **Почати з простого перекладу**, а складний читати паралельно:
   - сучасні прості переклади: *Traducción en Lenguaje Actual (TLA)*, *Dios Habla Hoy (DHH)*, *NVI*;
   - класичний: *Reina-Valera 1960*.
   - Схема: та сама глава українською → простий іспанський → Reina-Valera.
2. **Граматика, якої немає в розмовній мові:** `vosotros` і його форми, `pretérito` vs
   `imperfecto` в оповіді, `subjuntivo`, старі форми і порядок слів.
3. **Словник Біблії** — повторювані слова (`pacto`, `justicia`, `gracia`, `misericordia`,
   `arrepentirse`, `siervo`, `bienaventurado`…), веду список.
4. **З чого почати читати:** Євангеліє від Марка (коротке, проста оповідь) → Івана → Псалми / Притчі.

Переклад обираю я (якщо в громаді/церкві читають якийсь конкретний — беремо його).

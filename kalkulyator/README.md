## Ключові рішення Назара (не міняти без нього)
- Окремий продукт: **не пов'язаний з курсом і сайтом HLD Casa**.
- Спершу **точність**: кожна формула — золотий приклад + тест. Гроші в центах.
- Для «дядьків на об'єкті»: простий режим на екрані, решта згорнута в «Більше» **окремо в кожному блоці**; великі кнопки (48 px), підписи словами, «Видалити → Повернути», автозбереження.
- Розміри m²: два списки — «Стіни / площі — додаються» і «Вікна, двері, отвори — віднімаються», перемикач «метрах / сантиметрах»; або «Знаю площу». Без «× N», без назв частин, без правил порогу отворів у простому режимі.
- Ціна: просто число; валюта необов'язкова (за замовч. без валюти); «мені коштує» прибрано з екрана.
- «Запас і округлення» (запас % або m²; «округлити до», напр. 147 → 150) — під розмірами.
- Додаткові витрати: Матеріал → Доплата → Техніка; кожна згортається в рядок (Готово / Enter). Техніка спершу «просто сума», детально — по годинах. **Матеріали потребують окремої логіки** (мішки, пачки, відра) — потім.
- «Разом»: велика сума + розбивка + «виходить за 1 m² з усім»; знижка, податок (за замовч. без), етапи оплати — там же, згорнуто. Тонкий рядок-підсумок унизу екрана.
- Податки: «свій %» першим; утримання (retención) — сховано з поясненням.
- Монетизація потім: базова логіка безкоштовна; платне — в інтерфейсі/каталозі, не в ядрі.

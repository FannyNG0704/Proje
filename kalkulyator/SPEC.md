# Будівельний калькулятор — специфікація логіки (чернетка v0.1, 29.10.2026)

Мета: **ядро (логіка) без інтерфейсу**, яке точно рахує площі, матеріали, ціну й робочі години.
Окремий продукт, **не пов'язаний з курсом і сайтом**. Ядро окреме: потім на нього можна поставити застосунок, віджет або продати як бібліотеку.

Правило №1: **спершу правильні розрахунки й тести, потім дизайн.** Кожна формула має тест з прикладом, порахованим вручну.

---

## 1. Для кого (три напрямки — одне ядро)

| Напрямок | Хто користується | Що бачить | Що треба поверх ядра |
|---|---|---|---|
| **A. Віджет для сайтів** | клієнт | «моя кімната → орієнтовна ціна» | простий інтерфейс, без збереження |
| **B. Застосунок для майстра/бригади** | ти, брат, робітники | площі, матеріали, кошторис, **години й історія** | збереження (спершу в телефоні, потім сервер), PWA |
| **C. Продаж логіки** | інші фірми / розробники | бібліотека або API | документація, ліцензія, версії; для API — сервер |

**Рекомендація:** ядро → простий тестовий інтерфейс «як 95-й рік» → **B для себе** (бо ти сам — перший і найкращий тестувальник) → A (віджет) → C, коли ядро перевірене на реальних об'єктах.

## 2. Головна ідея структури: «виміряв один раз → застосував кілька робіт»

```
Об'єкт (obra)
 └─ Зона / кімната (Salón, Baño…)
     └─ Поверхня (стіна A, стеля, підлога, відкоси…)   ← геометрія, вимірюємо ОДИН раз
         └─ Роботи на поверхні (шари по черзі)          ← штукатурка → шпаклівка ×2 → ґрунт → фарба
             └─ Матеріали кожної роботи                 ← витрата, запас, упаковки, ціна
 └─ Додаткові роботи (з каталогу і довільні)
 └─ Непередбачені витрати (% або сума)
 └─ Кошторис: роботи + матеріали + додаткові → знижка → IVA → разом
```

Чому так: одна стіна 12 м² проходить 4–5 технологій. Якщо міряти окремо під кожну — помилки і подвійна робота.

---

## 3. Модуль «Геометрія»

**Поправка термінів:** стіна, підлога, стеля — це **площа (m²)**, не об'єм. Об'єм (m³) — тільки для стяжки, бетону, сміття.

| Що | Як задається | Формула |
|---|---|---|
| Прямокутна поверхня | ширина × висота | `a × b` |
| Складна поверхня | кілька прямокутників (+/−) або площа вручну | сума ± частин |
| Кімната | довжина, ширина, висота | стіни = `2 × (L + W) × H`, стеля/підлога = `L × W`, периметр = `2 × (L + W)` |
| Отвори (вікна, двері, ніші) | ширина × висота × кількість | віднімаються від площі |
| Відкоси (mochetas) | периметр отвору × глибина | **додаються** (окрема поверхня) |
| Погонні метри (ml) | довжина | плінтус, кути, профіль LED, карнизи, шви |
| Штуки (ud) | кількість | двері, світильники, розетки |
| Об'єм (m³) | площа × товщина | стяжка, наливна підлога |

**Правило віднімання отворів — налаштування, не жорсткий код** (у різних майстрів і країнах по-різному):
- `відняти всі` / `не віднімати менші за X m²` (часто 0,5–2 m²) / `відняти, але додати відкоси`.

**Перевірки:** від'ємні числа, нуль, отвори більші за стіну → помилка з поясненням, а не «−3 m²».

## 4. Модуль «Матеріали» (одна загальна формула для всіх)

```
потреба = база × норма × товщина(мм, якщо є) × шари
з_запасом = потреба × (1 + відходи%)
упаковок = ВГОРУ( з_запасом ÷ розмір_упаковки ) + запасних_упаковок
```
- **база** — m², ml, ud або m³ (з геометрії).
- **норма** — витрата на одиницю: кг/m²/мм, л/m², шт/m², m²/m² тощо.
- **режими:** «впритик» (відходи 0, без запасних) і «з запасом» (відходи % + N упаковок). Показуємо обидва.
- **округлення тільки вгору і тільки на кроці упаковок.** Проміжні числа не округлюємо.
- **Каталог матеріалів редагується** (назва, одиниця, упаковка, норма, ціна, джерело норми). Значення за замовчуванням — орієнтовні, з технічних карт виробників (*fichas técnicas*), перевіряємо перед використанням.

---

## 5. Технології (шаблони робіт)

Кожна технологія = **набір матеріалів + правила**. Норми нижче — **орієнтовні, всі редагуються**, перевірити з fichas técnicas.

| Технологія | Від чого рахуємо | Матеріали і логіка |
|---|---|---|
| **Штукатурка** (гіпс / цемент) | m² × товщина мм | кг = m² × мм × норма (гіпс ≈ 0,8–1,0 кг/m²/мм; цементна ≈ 1,5–1,8) → мішки; маяки (ml) |
| **Шпаклівка** (масилла) | m² × шари | кг = m² × норма шару × шари; **сітка/волокно** = m² × (1 + нахлест %); ґрунт між шарами |
| **Пладур — перегородка** | довжина × висота, сторони, шари листів | листи = ВГОРУ(площа × сторони × шари ÷ площа листа); стійки = ВГОРУ(довжина ÷ крок 400/600) + 1, довжина = висота; напрямні = 2 × довжина; саморізи ≈ шт/m²; стрічка ml; шпаклівка швів кг/m²; вата m² |
| **Пладур — стеля** | m² | листи, профілі за кроком, підвіси шт/m², периметр (ml) |
| **Плитка** (стіни/підлога) | m² + розмір плитки + упаковка | упаковки = ВГОРУ(m² × (1 + відходи) ÷ m² в упаковці); відходи: пряма 5–10 %, діагональ 12–15 %, великий формат — своє; **клей** кг/m² за гребінкою (6 мм ≈ 3–4, 10 мм ≈ 5–6, подвійне нанесення +); **затирка** за формулою виробника: `(A+B)/(A×B) × ширина шва × глибина × густина × m²`; хрестики/СВП; кути/профілі ml |
| **Фарбування** | m² × шари | л = m² × шари ÷ покриття (м²/л, ≈ 8–14); ґрунт окремо; округлення до відер 4/10/15 л — комбінація відер |
| **Наливна підлога / стяжка** | m² × товщина | кг = m² × мм × норма (≈ 1,5–2,0 кг/m²/мм) → мішки; стяжка — m³ |
| **Ламінат** | m² | упаковки з запасом (5–10 %), підкладка m², плінтус ml + кути |
| **Погонні роботи** | ml | плінтус, карниз, LED-профіль: ВГОРУ(ml ÷ довжина планки) з запасом на різи |
| **Поштучні** | ud | монтаж дверей, світильників: ціна × кількість |

**Пресети процесів (послідовність робіт однією кнопкою), бо в різних країнах роблять по-різному:**
- 🇪🇸 *Пладур під фарбу:* листи → шви (стрічка + 1–2 шари по швах) → ґрунт → фарба ×2.
- 🇺🇦 *Стіна «під покраску» по штукатурці:* штукатурка → шпаклівка 1 шар + сітка → 2-й шар → (3-й, якщо нерівно) → ґрунт → фарба ×2.
- Пресет можна змінити: вимкнути крок, додати шар.

## 6. Модуль «Кошторис» (гроші)

- Кожна робота: ціна праці за одиницю (m², ml, ud, година) + матеріали.
- **Додаткові роботи:** з каталогу (демонтаж, вивіз сміття, захист меблів…) і **довільні** («що з'явилось у процесі»): опис, кількість, одиниця, ціна.
- **Непередбачені:** % від суми або фіксована сума.
- Знижка, потім **IVA**: 21 % загальна; **10 % для ремонту житла приватної особи — тільки за умовами закону** (перевірити точні умови перед використанням; не вбивати в код як «завжди 10 %»).
- Вихід: таблиця по партиях (*partidas*): кількість, одиниця, ціна, сума → матеріали → додаткові → підсумки.
- **Гроші — в центах (цілі числа).** Інакше `0.1 + 0.2 = 0.30000000000000004` і копійки «зникають».

---

## 7. Модуль «Робочий час» (табель)

Окремий модуль, бо потребує **збереження й історії**.
- Працівник, об'єкт, дата, початок–кінець **або** кількість годин, перерви, прив'язка до роботи (партиди), нотатка.
- Підсумки: за день / тиждень / місяць / об'єкт / працівника; ставка → сума до оплати.
- Історія по датах; **виправлення зберігають, хто і коли змінив** (щоб не було суперечок).
- Підводні камені: зміна через північ, забута «кінець зміни», округлення (до 15 хв?), перерва, переробки, часовий пояс, робота без інтернету на об'єкті (запис має зберегтися і синхронізуватись пізніше).

## 8. Технічні рішення

| Рішення | Чому |
|---|---|
| **JavaScript (ES modules) + JSDoc-типи**, пізніше TypeScript | одна мова для застосунку, сервера й віджета; TS — коли будемо продавати |
| **Чисті функції:** дані на вхід → результат на вихід, без DOM | ядро працює і в браузері, і на сервері, і в застосунку |
| **Тести на вбудованому `node:test`** (без бібліотек) | кожна формула має «золотий» приклад, порахований вручну |
| Внутрішні одиниці: **метри, мм, кг, л, центи** | один стандарт → менше помилок перетворення |
| Каталог норм — **дані (JSON)**, не код | міняєш норму без програміста; пресети для ES / UA |
| Валідація входу з людськими помилками | «отвори більші за стіну» замість мовчазного мінуса |
| Версії каталогу й ядра | кошторис, зроблений рік тому, рахується так само |

## 10. Відкриті питання (відповідає Назар)

1. Перший користувач — **ти/бригада** чи **клієнт**?
2. Яке правило віднімання отворів ти використовуєш на практиці?
3. Якими матеріалами (марки) працюєш найчастіше — з них візьмемо реальні норми: штукатурка, шпаклівка, пладур, клей для плитки, фарба.
4. Мова інтерфейсу: іспанська, українська чи обидві?
5. **Золоті приклади:** 2–3 реальні об'єкти, де ти знаєш, скільки реально пішло матеріалу і грошей. Це головна перевірка, що калькулятор рахує правильно.

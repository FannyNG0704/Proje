# Логіка 02 — Структура позиції і одиниці виміру (v0.1)

Одна позиція = 5 блоків. Логіка однакова для будь-якої роботи (траншея, стіна, плитка…).
Різниця між роботами — тільки **які помічники виміру** і **пресети** доступні.

---

## Блоки позиції

| # | Блок | Обов'язково | Що всередині | Результат блоку |
|---|---|---|---|---|
| 1 | **Одиниця** | так | m² · ml · m³ · год · шт · одна сума | вибрана одиниця |
| 2 | **Кількість** | так (крім «одна сума») | вписати **або** виміряти (помічник) + запас кількості | кількість з запасом |
| 3 | **Ціна** | так | ціна за одиницю **або** одна сума; собівартість (необов.) | базова сума |
| 4 | **Додатково** | ні | сума вручну **або** розрахунки: техніка, штуки, доплата % | сума «додатково» (у заголовку блоку) |
| 5 | **Підсумок** | — | похибка %, надбавка/знижка %, податок | **до сплати** → «Зберегти» |

---

## Блок 2 — Кількість

| Поле | Варіанти |
|---|---|
| Спосіб | `вписати` (число) / `виміряти` (помічник для цієї одиниці, див. нижче) |
| Запас кількості | `+ одиниці` (напр. +3 m²) **або** `+ %` (напр. +7,5 %) — одне з двох |
| Показ | завжди обидва вигляди: «+3 m² = +7,5 %» |

```
кількість_з_запасом = кількість + запас_од            (або кількість × (1 + запас_%))
еквівалент_%        = запас_од ÷ кількість × 100
```

---

## Блок 3 — Ціна

| Поле | Варіанти |
|---|---|
| Режим | `за одиницю` (€/m² …) / `одна сума` (€ за всю позицію) |
| Ціна | число, € (до 4 знаків після коми для дрібних цін, напр. 0,355 €/кг) |
| Собівартість (необов.) | «моя ціна» за одиницю або сумою → показує маржу |

```
за одиницю:  базова = кількість_з_запасом × ціна
одна сума:   базова = ціна
маржа        = (ціна − собівартість) ÷ ціна × 100      (сценарій «мені 500, клієнту 700» → 28,6 %)
надбавка     = (ціна − собівартість) ÷ собівартість × 100  (→ 40 %)
```

---

## Блок 4 — Додатково

Список рядків; кожен рядок — один тип:

| Тип | Поля | Формула |
|---|---|---|
| Сума | назва, € | € |
| Штуки | назва, кількість, € за шт | к-сть × € |
| % від базової | назва, % | базова × % |
| Техніка | тип, години, €/год, простій год, €/год простою, мінімум, доставка | МАКС(год×€ + простій×€, мінімум) + доставка |
| Ділянка з іншими умовами | кількість, ціна або множник складності | к-сть × ціна × k |

Кожен рядок може мати позначку **«виникло в процесі»** + дата + причина.
`додатково = Σ рядків` — показується в заголовку блоку.

---

## Блок 5 — Підсумок (порядок дій фіксований)

```
1. сума_позиції  = базова + додатково
2. з_похибкою    = сума_позиції × (1 + похибка_%)            похибка: 0 за замовч.
3. скоригована   = з_похибкою × (1 + надбавка_% − знижка_%)   одне поле ±%
4. податки       = скоригована × ставка  (кожен окремо, округл. до цента)
5. до_сплати     = скоригована + податки(+) − утримання(−)
```
Показ: кожен рядок 1–5 видно окремо, з формулою.
Податок: IVA 21/10/0 · ПДВ · VAT · свій +% · утримання (retención 15/7, свій −%) · reverse charge (0 % + напис) · без податку.
**Зберегти** → позиція в кабінет (об'єкт / кошторис) з датою.

## Помічники виміру по одиницях

### m² — площа
| Помічник | Поля | Формула |
|---|---|---|
| Вписати | m² | — |
| Прямокутник | Д, Ш | Д × Ш |
| Кілька частин | список частин (+/−), кожна прямокутник або фігура | Σ(+) − Σ(−) |
| Фігури | трикутник (основа, висота) · трапеція (a, b, h) · коло (Ø) · півколо | ½·a·h · (a+b)/2·h · π·r² · π·r²/2 |
| Стіни кімнати | Д, Ш, висота (або периметр × висота) | 2·(Д+Ш)·В |
| Отвори | список: ширина × висота × к-сть; правило віднімання | − (за правилом) |
| Відкоси | периметр отвору (без низу або з), глибина | + |
| Похила поверхня | площа в плані + кут° або ухил % | площа ÷ cos(кут); ухил%: площа × √(1 + (ухил/100)²) |
| Сторони | × 1 / × 2 (паркан з двох боків, перегородка) | × сторони |

**Правило віднімання отворів (пресети, редагується; перевірити за чинними нормами перед релізом):**
| Пресет | Правило |
|---|---|
| Не віднімати | 0 |
| Відняти всі | всі отвори |
| Відняти > X m² | тільки отвори більші за X (типові X: 0,5 · 1 · 2,5 · 3 · 4) |
| Відняти + додати відкоси | всі отвори − , відкоси + |

### ml — погонні метри
| Помічник | Поля | Формула |
|---|---|---|
| Вписати | ml | — |
| Відрізки | список довжин | Σ |
| Периметр | Д, Ш (прямокутник) · або кімната | 2·(Д+Ш) |
| Мінус прорізи | список ширин (двері для плінтуса) | − Σ |
| Похила довжина | довжина в плані + перепад висоти (або ухил %) | √(Д² + h²) |
| Коло / дуга | Ø або радіус + кут | π·Ø · (кут/360)·2·π·r |
| Сторони / ряди | × N (лаги в 3 ряди) | × N |

### m³ — об'єм
| Помічник | Поля | Формула |
|---|---|---|
| Вписати | m³ | — |
| Брусок | Д, Ш, Г | Д × Ш × Г |
| Площа × товщина | площа (або m²-помічник), товщина см/мм | площа × товщина(м) |
| Траншея прямокутна | Д, Ш, Г, к-сть | Д·Ш·Г·n |
| Траншея з укосами | Д, ширина дна, Г, укіс m (або ширина зверху) | (дно + верх)/2 · Г · Д |
| Змінна глибина | Д, Ш, Г на початку, Г в кінці | Д · Ш · (Г1 + Г2)/2 |
| Котлован | Д, Ш, Г, робочий запас | (Д+2з)·(Ш+2з)·Г |
| Ями (циліндр) | Ø, Г, к-сть | π·(Ø/2)²·Г·n |
| Розпушення (показник) | коефіцієнт k (1,10–1,60) | об'єм × k — **тільки для вивозу**, ціну копання не міняє |

### шт — штуки
| Помічник | Поля | Формула |
|---|---|---|
| Вписати | шт | — |
| За кроком | довжина, крок, кінці (обидва / один / жодного) | ВГОРУ(Д ÷ крок) + 1 / + 0 / − 1 |
| За площею | площа, шт на m² | ВГОРУ(площа × шт/m²) |

### год — години
| Помічник | Поля | Формула |
|---|---|---|
| Вписати | год | — |
| Початок–кінець | час початку, кінця, перерва хв | (кінець − початок) − перерва (через північ: + 24 год) |
| Дні | днів × год на день | д × г |
| Люди | людей × години | л × г |

### одна сума
Без кількості. Блок 2 прихований. Ціна = сума.

## Загальні правила

| Правило | |
|---|---|
| Внутрішні одиниці | метри, m², m³, години, центи |
| Ввід см/мм | поле знає свою одиницю; перевід ×0,01 / ×0,001 явно |
| Округлення | кількості — не округлюються; гроші — до цента, тільки на кроках 1–5 і в рядках «Додатково»; спосіб «половина вгору» |
| Перевірки | розміри > 0; отвори ≤ поверхні; кінець ≥ початок (або через північ); % від −100 до +1000 |
| Пояснення | кожен результат має рядок «як порахували» |
| Однакова логіка | помічник «m³ брусок» той самий для траншеї, стяжки, бетону — різні тільки пресети |

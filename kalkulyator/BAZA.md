# БАЗА калькулятора — логіка по шарах (v1.0, 30.10.2026)

Головний документ. Порядок — **від того, що спільне для всього, до того, що окреме**.
Що вище в списку — тим більше на ньому «стоїть» і тим ретельніше тестується.

```
Шар 0  Спільне ядро        ← використовують усі
Шар 1  Підсумок            ← один на всі одиниці
Шар 2  Ціна                ← одна на всі одиниці
Шар 3  Кількість (каркас)  ← однаковий: + частини − частини → правка → запас
Шар 4  Геометрія           ← єдине, що різне:  ml  →  m²  →  m³
Шар 5  Прості режими       ← шт · год · одна сума
Окремо Табель годин        ← не частина калькулятора, свій модуль
```

**Ключова ідея накладання:** `ml ⊂ m² ⊂ m³`.
- m² будується з довжин (ml): стіни = периметр × висота.
- m³ = **будь-яка фігура m² × глибина/товщина** (брусок = прямокутник × глибина, яма = коло × глибина, траншея з укосами = трапеція × довжина).
Тому пишемо в порядку **ml → m² → m³**, і m³ не має своєї окремої «геометрії» — тільки «× глибина».

---

## Шар 0 — Спільне ядро

| № | Що | Правило |
|---|---|---|
| 0.1 | Гроші | тільки **центи** (цілі числа). Ціни за одиницю — до 4 знаків (зберігати в десятитисячних евро, 1 € = 10000) |
| 0.2 | Округлення | гроші до цента «половина вгору»; **тільки** на сумах рядків і податках; кількості не округлюються |
| 0.3 | Одиниці | всередині: м, m², m³, год; ввід см/мм — поле знає свою одиницю, перевід явний |
| 0.4 | Ручна правка | **будь-яке** пораховане число можна замінити руками; зберігається `{порахувано, правка}`; далі використовується правка; показ «2,73 → 3,00 (ручна правка)» |
| 0.5 | Пояснення | кожен результат має рядок «як порахували» з числами |
| 0.6 | Перевірки | розміри > 0; віднімання ≤ додавання; % у межах −100…+1000; помилка = текст людською мовою, **ніколи** тихий 0 чи мінус |
| 0.7 | Позначка «в процесі» | будь-який рядок може мати: дата + причина (з'явилось після домовленості) |

## Шар 1 — Підсумок (один на всі одиниці, порядок фіксований)

| Крок | Назва | Формула | За замовч. |
|---|---|---|---|
| 1.1 | Базова | з Шару 2 (кількість × ціна, або одна сума) | — |
| 1.2 | Додатково | Σ рядків: сума € · шт × € · % від базової · техніка | 0 |
| 1.3 | Сума позиції | 1.1 + 1.2 | — |
| 1.4 | Похибка | 1.3 × (1 + похибка %) | 0 % |
| 1.5 | Корекція | 1.4 × (1 ± %) — надбавка або знижка; **або** сума € | 0 |
| 1.6 | Податки | кожен: 1.5 × ставка, округлення до цента; додає (IVA/ПДВ/VAT/свій) або віднімає (retención/свій); reverse charge = 0 % + напис | без податку |
| 1.7 | До сплати | 1.5 + податки(+) − податки(−) | — |

**Техніка** (рядок у 1.2): `МАКС(год × €/год + простій × €/год, мінімум) + доставка`.
Для m² техніка просто не пропонується за замовчуванням — але «Додатково» є завжди.

## Шар 2 — Ціна (одна на всі одиниці)

| № | Поле | Варіанти |
|---|---|---|
| 2.1 | Режим | за одиницю (€/m², €/ml, €/m³, €/шт, €/год) · одна сума |
| 2.2 | Ціна | ввести · вибрати з **моїх цін** (особистий прайс користувача) · з запропонованих (пресет країни, орієнтовні) |
| 2.3 | Собівартість | необов.: «мені коштує» за одиницю або сумою |
| 2.4 | Результат | базова = кількість_з_запасом × ціна (або = одна сума); маржа % = (ціна − собів.) ÷ ціна; надбавка % = (ціна − собів.) ÷ собів. |

---

## Шар 3 — Кількість (каркас однаковий для ml, m², m³)

```
кількість = Σ(частини +) − Σ(частини −)          ← частини з Шару 4 або просто числа
          → ручна правка (0.4), якщо є
          → запас: + одиниці  АБО  + %           (показ обох: «+3 m² = +7,5 %»)
          = кількість_з_запасом
```
| № | Правило |
|---|---|
| 3.1 | Частина «+» або «−» = **число** (вже відома кількість) **або** фігура (Шар 4) |
| 3.2 | Частина має назву (необов.): «стіна А», «вікно», «двері», «козирок», «своє» |
| 3.3 | Частина має множник «× N» (5 однакових вікон; 2 сторони паркану) |
| 3.4 | Мінус — це та сама частина з `знак = −` (вікно, двері, отвір, колона) |
| 3.5 | Порожній список = помилка «додай хоча б одну частину або впиши кількість» |

## Шар 4 — Геометрія (єдине, що відрізняється)

### 4A. ml — довжина (найпростіша, на ній стоїть m²)
| Фігура | Поля | Формула |
|---|---|---|
| Відрізок | Д | Д |
| Периметр прямокутника | Д, Ш | 2(Д+Ш) |
| Похилий відрізок | Д в плані + перепад h **або** ухил % | √(Д² + h²) · Д·√(1+(у/100)²) |
| Коло / дуга | Ø **або** r + кут | π·Ø · 2πr·кут/360 |

### 4B. m² — площа (будується на 4A)
| Фігура | Поля | Формула |
|---|---|---|
| Прямокутник | Д, Ш | Д·Ш |
| Трикутник | основа, висота | ½·a·h |
| Трапеція | a, b, h | (a+b)/2·h |
| Коло / півколо | Ø | π·r² · π·r²/2 |
| Стіни кімнати | периметр (4A) × висота | P·В |
| Відкіс | периметр отвору (4A) × глибина | P·г |
| Похила поверхня | площа в плані + кут° **або** ухил % | S ÷ cos(кут) · S·√(1+(у/100)²) |

**Правило отворів** (налаштування позиції): не віднімати · відняти всі · відняти > X m² · відняти + додати відкоси.
Застосовується **тільки** до частин, позначених як отвір.

### 4C. m³ — об'єм (= фігура 4B × глибина)
| Фігура | Як | Формула |
|---|---|---|
| Брусок | прямокутник × Г | Д·Ш·Г |
| Шар | будь-яка площа 4B × товщина (см/мм) | S·t |
| Траншея з укосами | трапеція (дно, верх або укіс m, Г) × Д | (b+T)/2·Г·Д, T = b + 2mГ |
| Змінна глибина | прямокутник × (Г1+Г2)/2 | Д·Ш·(Г1+Г2)/2 |
| Котлован з запасом | (Д+2з)(Ш+2з) × Г | — |
| Яма / стовп | коло × Г | π·r²·Г |
| Розпушення | **показник**, не кількість ціни | V·k (k 1,10–1,60) — для вивозу |

## Шар 5 — Прості режими (без геометрії)

| Режим | Кількість | Ціна | Своя корисна функція |
|---|---|---|---|
| **шт** | число · за кроком (довжина ÷ крок, кінці: обидва +1 / один 0 / жодного −1, вгору) · за площею (S × шт/m², вгору) | €/шт | крок для стовпів, профілів, кріплень |
| **год** | число · дні × год · люди × год | €/год | швидкий розрахунок оплати; **записи часу — це Табель, не тут** |
| **одна сума** | — | € за все | **етапи оплати**: аванс / проміжні / фінал у % або € (сума = 100 %), з датами; + маржа від собівартості; + податок |

## Окремо — Табель годин (свій модуль, не калькулятор)

| Поле | |
|---|---|
| Хто | працівник (робітник пише сам або прораб за нього) |
| Об'єкт, дата | |
| Час | початок–кінець − перерва (через північ +24 год) **або** число годин |
| Що робив | текст |
| Скільки зробив | кількість + одиниця (25 m²) → продуктивність m²/год |
| Ставка | €/год → сума за день / тиждень / місяць / об'єкт |
| Історія змін | хто, коли, що змінив (суперечки) |

## Як це лягає на код (одна папка — один шар)

```
core/comun/       0.x  dinero, redondeo, unidades, correccion_manual, explicacion, validacion
core/resumen/     1.x  extras, maquinaria, error, ajuste, impuestos, total
core/precio/      2.x  precio, coste_margen
core/cantidad/    3.x  partes(+/−), reserva
core/geometria/   4A lineal.js · 4B superficie.js · 4C volumen.js   (m² імпортує ml, m³ імпортує m²)
core/simples/     5.x  unidades.js · horas.js · suma_global.js (etapas de pago)
modulos/fichaje/  табель
datos/            пресети країн, ставки податків, коефіцієнти (JSON з датою «актуально на»)
tests/            по файлу на модуль + golden.test.js
```
Помилка в `volumen.js` не чіпає m² і ціну: m³ **використовує** m², але m² про m³ нічого не знає.

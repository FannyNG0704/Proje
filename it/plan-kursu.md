# Курс IT «Від нуля до проду»

Повна версія з задачами, схемами, сленгом і відмітками прогресу — сторінка курсу:
https://claude.ai/artifact/7a82nP9mL1FagUNTNyd5Ww (вихідний файл: `it/kurs.html`).

## Принцип

1. Проєкт спочатку, теорія під нього.
2. Доводимо до кінця — блок «Готово, коли…» у кожному проєкті.
3. Підводні камені — до старту.
4. Спіраль: безпека, помилки, дані, деплой повертаються щоразу глибше.
5. Одна мова на все: JavaScript / TypeScript.
6. Ланцюжок «якщо X → думай про Y» (`it/karta-ryzykiv.md`).

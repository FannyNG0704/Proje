# Наскрізний проєкт курсу 1: сайт будівельної фірми (Іспанія)

Ідея (26.10.2026): сайт для будівельної / ремонтної фірми в Іспанії. Досвід: брат — прораб, сам брали об'єкти; я в Іспанії — підсобник, потім майстер. Знаю структуру робіт, іспанська ~B2.

## План по проєктах курсу
- P1 — односторінковий сайт: послуги, галерея «до/після», етапи роботи, переваги, відгуки, контакти + форма (Formspree), адаптив, домен.
- P2 — калькулятор приблизної ціни (м² × тип робіт, IVA, центи).
- P4 — карта / погода (планування робіт).
- P5 — Telegram-бот для заявок.
- P6–P7 — сервер, база заявок, адмінка з логіном.
- Фінал — запис на огляд об'єкта, передоплата.
- Курс 2 — відео «до/після», 3D-візуалізація; Архітектура AR17 — 3 мови (es/uk/en); AR20 — aviso legal, cookies.

## Підготувати до старту P1
1. Назва (можна умовна), місто/район.
2. Послуги 4–8.
3. Фото робіт 6–12 («до/після»).
4. 3 переваги.
5. Етапи роботи 3–5 (дзвінок → огляд → presupuesto → роботи → здача).
6. Контакти (WhatsApp, телефон, email, години).
7. 3–5 сайтів конкурентів (reformas integrales + місто): що подобається / ні.
8. 2–3 відгуки.

Спершу проста сторінка, зроблена повністю і задеплоєна. «Фішки» — у наступних проєктах.

## Рішення власника (26.10.2026) — пам'ятати при написанні сайту
- Сайт = «компанія», без «я / брат», без віку; компанія може рости (наймані працівники).
- Основний обсяг робіт (~80% замовлень): yeso, pladur (коробки, стелі, foseado з LED), шпаклівка/alisado Q3–Q4, фарбування, плитка, фасади (вкл. декоративну фактуру губкою — уточнити іспанську назву), гідроізоляція, балюстради, дрібні роботи й монтажі.
- Сантехніку/електрику НЕ писати, але блок «¿Necesita otro trabajo? Consúltenos» — домовитись можна. Нове будівництво не беремо.
- Не писати список «що не робимо».
- Вся провінція Малага, без доплат. Огляд безкоштовний. Дрібні роботи беремо.
- Терміни, гарантія, оплата, матеріал — «a convenir».
- **Технічно:** ціни й послуги — в окремих даних (масив/JSON), не в розмітці: легко міняти ціну і додавати роботу. Дві ціни: тільки робота / з матеріалом. Прайс з анкети → калькулятор P2.
- Слайдер робіт з фото й підписами, свайп убік: у P1 — простий CSS scroll-snap; красиві анімації — курс 2.
- Власник зараз живе в Торрев'єсі, переїжджає в Малагу.

- Підводний камінь: повноекранний preloader ховає контент → гірший LCP / Performance і довше «бачу білий екран». Розглянути: показ не довше N секунд, тільки при повільному завантаженні, або skeleton замість повного екрана.
- **Ідея анімації (чернетка, може змінитись):** D з очима, повернута як смайлик (D = усмішка, очі збоку), по центру екрана крутиться / «живе», поки йде завантаження. Коли все завантажилось — D повертається у звичайне положення, і з неї виїжджають L, H і CASA (як у нашій анімації логотипа). Нагадати, коли дійдемо до preloader.

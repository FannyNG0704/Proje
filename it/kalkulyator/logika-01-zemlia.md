# Логіка 01 — Позиція, кошторис і земляні роботи (v0.1, 29.10.2026)

Статус: **обговорюється**, коду ще немає. Після затвердження — пишемо тести за «золотими прикладами» (розділ 9), потім код.

## 1. Простими словами

1. **Все в калькуляторі — це «позиція»** (*partida*, *line item*): назва → скільки → по якій ціні → сума.
2. **Скільки** можна вписати одразу («12 м») або дати калькулятору порахувати з розмірів («довжина × ширина × глибина»).
3. **Ціну** вибираєш сам: за метр, за m², за m³, за годину, або **одна сума за все** («за 120 € викопаю»).
4. До позиції можна додати **доплати**: викорчувати дерево, пробили трубу, важкий ґрунт, додатковий інструмент.
5. Якщо працює **техніка** — окремий блок: години, простій, доставка, «мінімум за виїзд».
6. Усі позиції падають у **кошторис**. Там знижка і **податки** (IVA, утримання, без податку, свій %).
7. Біля кожної суми видно, **як вона порахована** — щоб ти і клієнт бачили, що нічого не вигадано.

## 2. Позиція (Partida) — структура

| Поле | Що це | Приклад |
|---|---|---|
| `nombre` | назва | «Траншея під кабель» |
| `categoria` | розділ | Земляні роботи |
| `unidad` | одиниця ціни | `ml`, `m2`, `m3`, `ud`, `h`, `dia`, `t`, `global` (одна сума) |
| `cantidad` | кількість в одиницях ціни | 12 |
| `origen_cantidad` | `manual` або `ayudante` (порахована з розмірів) | ayudante: траншея |
| `precio_unitario` | ціна за одиницю (центи) | 1000 (= 10,00 €) |
| `coef_dificultad` | множник складності (за замовч. 1) | 1,3 — глина |
| `extras[]` | доплати (див. розд. 5) | дерево, 80 € |
| `maquinaria` | блок техніки (розд. 6), необов'язковий | екскаватор 4 год |
| `es_adicional` | «з'явилось у процесі» + дата + причина | так, 05.11, «скеля на 40 см» |
| `nota` | будь-який текст | — |

### Формула позиції
```
базова    = ОКРУГЛ_ЦЕНТ( cantidad × precio_unitario × coef_dificultad )
доплати   = Σ extras
техніка   = сума блоку техніки (якщо є)
сума      = базова + доплати + техніка
```
Якщо `unidad = global`: `базова = precio_unitario` (кількість не множиться).

## 2a. Ділянки (tramos) — одна позиція, різні умови

Реальний сценарій: траншея 100 м, перші 80 м — звичайний ґрунт вручну, останні 20 м — каміння, потрібна техніка.
Тому позиція може мати **кілька ділянок**, кожна зі своїми розмірами, ціною, складністю і технікою:

```
позиція «Траншея під кабель»
  ділянка 1: 80 ml × 0,20 × 0,50, 10 €/ml, складність 1,0
  ділянка 2: 20 ml × 0,20 × 0,50, 10 €/ml, складність 1,5 + техніка 3 год (es_adicional, 05.11, «каміння»)
сума позиції = Σ ділянок + доплати позиції
```
- За замовчуванням ділянка **одна** — людина її навіть не бачить. «+ ділянка» — тільки коли треба.
- Кожна ділянка має свою одиницю ціни? **Ні** — одиниця одна на позицію (інакше незрозуміло, що сумувати). Інша одиниця = інша позиція.
- Збільшити ціну через важкий ґрунт можна трьома способами (всі дають прозорий результат):
  1. `складність ×k` на ділянці; 2. інша ціна за одиницю на ділянці; 3. доплата / техніка з позначкою «додатково».

## 3. Помічник кількості — траншея

**Вхід:** довжина `L` (м), ширина `B` (м або см), глибина `H` (м або см), кількість однакових траншей `n` (за замовч. 1).
Необов'язково: **укоси** (траншея ширша зверху) — ширина зверху `T`, або коефіцієнт укосу `m`.

```
прямокутна:   об'єм_m3   = L × B × H × n
з укосом:     T          = B + 2 × m × H          (якщо задано m)
              переріз_m2 = (B + T) / 2 × H         (трапеція)
              об'єм_m3   = переріз × L × n
погонні:      ml         = L × n
```
**Що повертає помічник:** одразу `ml`, `m3` (у землі), `m2` дна (`L × B × n`) — і ти вибираєш, в якій одиниці береш ціну.

**Розпушення (для вивозу і машин):** `об'єм_розпушений = об'єм × k_розп`, де
пісок ≈ 1,10–1,15 · звичайний ґрунт ≈ 1,20–1,25 · глина ≈ 1,30–1,40 · скеля ≈ 1,40–1,60.
(Орієнтовно; редагується.) **На ціну копання не впливає** — тільки на «скільки вивезти / скільки рейсів».

**Перевірки:** всі розміри > 0; ширина/глибина в см переводяться в м (÷100) **явно** — поле знає свою одиницю; укіс не від'ємний.

## 4. Помічники — зняття шару, котлован, демонтаж

| Робота | Вхід | Повертає |
|---|---|---|
| **Зняття шару** (родючий ґрунт, старе покриття) | площа (або Д × Ш), товщина | `m2` = площа; `m3` = площа × товщина |
| **Котлован** | Д × Ш × Г, робочий запас навколо (м) | `m3` = (Д + 2·запас) × (Ш + 2·запас) × Г |
| **Розчистка / планування** | Д × Ш або площа | `m2` |
| **Демонтаж** | залежно від того, що: площа / довжина / штуки / одна сума | `m2` / `ml` / `ud` / `global` |

Площа може бути **сумою кількох прямокутників** (ділянка буквою «Г») — список частин, кожна Д × Ш, мінус вирізи.

## 5. Доплати (extras)

Кожна доплата — міні-позиція: назва + один із типів:

| Тип | Формула | Приклад |
|---|---|---|
| `fijo` (фіксована) | сума | «Викорчувати дерево» 80 € |
| `por_unidad` | кількість × ціна | «Пробивка скелі» 3 ml × 25 € |
| `porcentaje` | % від базової суми позиції | «Робота в стиснених умовах» +15 % |

**Важкий ґрунт — два способи (обидва є):**
- **Наперед**: `coef_dificultad` (ґрунт видно одразу).
- **В процесі**: окрема доплата з `es_adicional = так`, датою і причиною («після 30 см скеля»). Так у кошторисі видно, що це **не було в початковій ціні** — це захищає в суперечці.

## 6. Техніка (maquinaria)

Окремий блок усередині позиції або **окрема позиція** «Техніка».

| Поле | Приклад |
|---|---|
| тип | міні-екскаватор / віброплита / навантажувач |
| ціна за годину | 45 € |
| години роботи | 4 |
| години простою + ціна простою (якщо інша) | 1 год × 30 € |
| доставка / виїзд (`transporte`) | 120 € |
| мінімум за виїзд | 200 € |

```
робота   = години × ціна_год + години_простою × ціна_простою
техніка  = МАКС( робота, мінімум ) + доставка
```
(Мінімум застосовується до роботи; доставка зверху — як найчастіше рахують. Налаштування можна змінити.)

**Підводний камінь:** на маленькій роботі фіксовані суми (доставка, мінімум) роблять ціну за m³ у 2–3 рази вищою. Калькулятор показує і «ціну за одиницю з технікою», щоб це було видно.

## 7. Кошторис і податки

```
підсумок     = Σ суми позицій                         (в центах)
знижка       = % або сума, від підсумку
база         = підсумок − знижка                      (base imponible)
для кожного податку:
   податок_i = ОКРУГЛ_ЦЕНТ( база × ставка_i )
   додає  (IVA 21/10/0, ПДВ, VAT, sales tax, свій +%)  → +
   віднімає (retención IRPF 15/7, свій −%)             → −
до сплати    = база + Σ податків(+) − Σ податків(−)
```
- Податки вибираються **на рівні кошторису**, не позиції (простіше; можна розширити пізніше, якщо в одному кошторисі різні ставки).
- Пресети за країною: **ES** — IVA 21 %, 10 % (ремонт житла приватної особи — тільки за умовами закону, перевірити), 0 %; retención 15 % / 7 %. **UA** — ПДВ 20 % або без. **US** — sales tax свій %. **Свій %**.
- **Інші країни Європи (ПДВ/VAT, орієнтовно, перевіряти перед релізом):** DE 19 % / 7 %, FR 20 % / 10 % (ремонт житла) / 5,5 %, IT 22 % / 10 %, PT 23 % / 6 %, PL 23 % / 8 % (житло), UK 20 % / 5 %. Ставки — **дані** (JSON з датою «актуально на»), не код.
- **Reverse charge (зворотне оподаткування)** — важливо для Європи: коли субпідрядник працює на іншу будівельну фірму, ПДВ у рахунку **не нараховується**, його платить замовник. Іспанія — *inversión del sujeto pasivo* (subcontratas en obra), Німеччина — *§13b UStG*, UK — *domestic reverse charge* (CIS). У калькуляторі: податок «0 % + обов'язковий напис у документі».
- **Поправка:** «податку автономо», який додається клієнту, **немає**. Cuota autónomo і IRPF ти платиш сам із заробленого.

## 8. Числа й округлення (правила, які не можна порушувати)

1. **Гроші — тільки в центах (цілі числа).** 10,00 € = 1000.
2. Кількості — десяткові (метри, m³), **не округлюємо** до кінця.
3. Округлення до цента — **один раз на суму позиції** і **один раз на кожен податок**. Спосіб: до найближчого, «половина вгору» (0,5 → 1).
4. Одиниці зберігаються **в метрах**; см/мм переводяться при вводі.
5. Кожна сума має **«пояснення»**: рядок з формулою і числами (`12 ml × 10,00 € = 120,00 €`).

## 10. Як буде виглядати для людини (майбутній інтерфейс, для розуміння)

1. «+ Додати роботу» → вибір з каталогу (Траншея) або «своя робота».
2. Одиниця: **ml / m² / m³ / година / одна сума** — кнопки.
3. Вибрав **m³** → з'являються поля «довжина · ширина · глибина» (або «вписати m³ вручну»).
4. Поле **ціна** за вибрану одиницю.
5. Під позицією: «+ доплата», «+ техніка», «складність ×».
6. Знизу — кошторис: податки кнопками (IVA 21 / 10 / без / свій %).
Просто на екрані → всередині вся логіка вище.

## 11. Європа — як міряють земляні роботи (щоб пресети були правильні)

| Країна | Правила обміру | Що важливо для логіки |
|---|---|---|
| **Німеччина** | VOB/C, DIN 18300 | обмір **в m³ у природному заляганні** (не розпушений); з 2015 ґрунти — «*Homogenbereiche*» замість старих класів 1–7 → наш «множник складності» |
| **Франція** | DTU / CCTP, *terrassement* | m³ в природному заляганні + *foisonnement* (розпушення) для вивозу; *tranchée* часто за ml |
| **UK / Ірландія** | NRM2 (*New Rules of Measurement*) | excavation в m³, *disposal* окремо, *working space* окремою позицією (наш «робочий запас» у котловані) |
| **Польща** | KNR (каталоги норм, як в Україні) | m³ + категорії ґрунту I–XVI; ручна/механізована окремо |
| **Іспанія** | бази цін (CYPE, бази автономій) | m³ або ml, desbroce m², esponjamiento для транспорту |

Висновок: **загальноєвропейське правило** — копання рахують **в об'ємі в природному заляганні**, а розпушення — лише для вивозу і транспорту. Наша логіка вже так працює. Відмінності — тільки пресети (назви, групи ґрунту, ставки ПДВ).

- Кожен модуль — **чисті функції** (дані → результат), без інтерфейсу.
- **Безкоштовне / платне вирішується в інтерфейсі й каталозі, не в ядрі.** Ядро однакове для всіх — так не буде двох версій логіки з різними помилками.
